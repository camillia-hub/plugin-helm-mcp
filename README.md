# Helm MCP

Manages Helm releases. This plugin installs and configures it in your workspaces.

Upstream server docs: https://www.npmjs.com/package/helm-mcp

Installs from the Camillia hub as `helm-mcp-48640a`. On every new task the plugin posts
the ready-to-paste `mcp.servers` entry and the setup steps as a task comment.
